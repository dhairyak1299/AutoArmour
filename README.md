# Auto Armor (Forge 1.8.9)

Build: install JDK 8, download the Forge 1.8.9 MDK (1.8.9-11.15.1.2318), then either
  a) copy this folder's `src/` into the MDK and run `gradlew build`, or
  b) use this folder as-is after adding the MDK's gradle wrapper files (gradlew, gradlew.bat, gradle/).
Result: build/libs/AutoArmor-1.0.0.jar -> put in .minecraft/mods

Use: press B in-game to open the settings GUI. Rebind under Controls > "Auto Armor".
Config file: .minecraft/config/autoarmor.cfg
